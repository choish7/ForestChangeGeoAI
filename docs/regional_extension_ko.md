# 다른 지역으로 확장하는 방법 (춘천 → 인제 시험 기준)

춘천에서 만든 AlphaEarth 산림변화 모델과 의사결정 지원 도구를 다른 시·군에 적용하는 절차입니다.
강원특별자치도 인제군(51810)에서 실제로 시험한 결과(E10, 2026-10-31)를 기준으로 정리했습니다.

## 1. 결론

- **임베딩 신호는 그대로 옮겨집니다.** 클래스별 AlphaEarth 거리 중앙값이 춘천과 인제에서 거의 같습니다(벌채·갱신 0.211 / 0.206, 산림증가 0.080 / 0.083, 전용 0.042 / 0.039, 무변화 0.031 / 0.025).
- **결정 임계값은 지역마다 다시 맞춰야 합니다.** 춘천 모델을 재학습 없이 쓰면 정밀도는 0.95 이상이지만, 신호가 약한 전용·산림증가를 많이 놓칩니다. 임계값만 0.5 → 0.2로 낮춰도 AE+S2 F1이 0.823 → 0.861로 올라, 인제 자체 학습(0.847 ± 0.082) 수준이 됩니다.
- **지형 특징은 옮기지 않습니다.** 지형(표고·경사)을 더하면 인제 F1이 0.823 → 0.760으로 떨어집니다. 지역마다 지형 분포가 달라 학습 지역에 과적합된 특징입니다.
- **변화유형 분류기는 옮겨집니다.** 인제 전이 macro-F1 0.776(춘천 0.785)으로, 표본이 적은 인제 자체 학습(0.686 ± 0.130)보다 낫습니다.
- **변화 시점 신호도 같습니다.** 사업실적 연도와 AE 정점 연도의 ±1년 일치율이 인제 78.8%(33개 소반), 춘천 77.4%(31개 소반)입니다. 주벌은 대부분 사업연도 1년 뒤에 정점이 나타납니다.

| 특징 | 춘천 홀드아웃 F1 | 인제 전이 F1 (P / R) | 인제 전이, 임계값 0.2 | 인제 자체 공간 CV F1 |
|---|---|---|---|---|
| AE (75) | 0.933 | 0.778 (0.955 / 0.656) | 0.825 | 0.792 ± 0.119 |
| S2 (6) | 0.764 | 0.755 (0.828 / 0.694) | — | 0.727 ± 0.062 |
| AE+S2 (81) | 0.936 | 0.823 (0.960 / 0.721) | 0.861 | 0.847 ± 0.082 |
| AE+S2+TERR (83) | 0.934 | 0.760 (0.969 / 0.625) | 0.800 | 0.843 ± 0.089 |

전체 수치는 `paper/revision/results/E10_inje_transfer.json`에 있습니다.

## 2. 그대로 쓰는 것과 지역마다 정하는 것

| 구성요소 | 다른 지역 적용 | 조치 |
|---|---|---|
| AlphaEarth 임베딩 특징(75개), 거리 계산 | 그대로 | 전국 공통 자료(GEE)이므로 코드 변경 없음 |
| Sentinel-2 NDVI·NBR 특징 | 그대로 | 합성 기간(6–9월)·구름 마스크 동일하게 유지 |
| 지형 특징 | 지역 의존 | 전이 모델에서 제외하거나 지역 표본으로 재학습 |
| 변화 라벨 규칙(임상도 2시기 비교) | 조건부 | 임상도 코드 체계가 같으면 그대로. 다른 도면·국가 자료면 5장 체크리스트로 재정의 |
| 결정 임계값 | 지역 의존 | 소규모 지역 표본(또는 육안 판독)으로 보정 |
| 변화유형 분류기 | 그대로 | 전용 클래스는 두 지역 모두 표본이 적어 후보로만 사용 |
| 공간 블록 검증(5 km) | 그대로 | 블록은 지역 좌표로 다시 생성 |
| 의사결정 서비스의 판정 기준값(회복률·NDVI 감소 등) | 지역 의존 | 춘천 자료로 정한 잠정값. 지역 표본으로 확인 후 조정 |
| 도구·수치 추적·보고서 구조 | 그대로 | 자료 경로·지역 코드만 바꿈 |

## 4. 절차

인제 시험에서 쓴 스크립트를 순서대로 실행합니다. 지역을 바꿀 때는 각 스크립트 상단의 경로 상수(`SRC`, `MAPS`, `PLAN_XLS`, `STANDS`)만 바꿉니다.

1. **라벨·표본 만들기 (로컬, 약 10분):** `python paper/revision/inje_prepare.py`
    - 임상도 2019·2025 중첩 → 0.1 ha 미만 조각 제거 → 춘천과 같은 규칙(`forest-change-agent/fcd/labels.py`)으로 무변화·벌채/갱신·전용·산림증가 분류
    - 클래스별 표본(무변화 1,000, 벌채·갱신 500, 전용 300, 산림증가 300), 15 m 내부 버퍼, 같은 10 m 화소 중복 제거, 5 km 블록 번호
    - 사업실적 2020~2024(주벌, 조림예정지정리·인공갱신) 소반마다 내부 최대 5점
    - 인제는 중첩에 505초, 조각 50,063개가 걸렸습니다
2. **표본을 GEE 자산으로 올리기:** 표본 표를 `ee.batch.Export.table.toAsset`으로 `projects/<프로젝트>/assets/<지역>_transfer/`에 올립니다(인제 시험에서 쓴 코드는 `inje_transfer_colab.py` 상단 설명 참고). Colab에서도 같은 자산을 읽을 수 있어 파일 전송이 필요 없습니다.
3. **특징 추출·전이 평가 (Colab 또는 로컬):** `python paper/revision/inje_transfer_colab.py --project <프로젝트>`
    - 기준 지역(춘천)과 대상 지역의 특징을 같은 코드로 추출합니다. 8,283점 추출에 1분이 채 걸리지 않았습니다.
    - 기준 지역 학습 모델을 재학습 없이 적용(전이 F1), 대상 지역 자체 5 km 블록 교차검증(기준선), 변화유형 분류, 사업실적 시점을 한 번에 계산합니다.
    - 먼저 기준 지역 홀드아웃 재현값을 확인합니다. AE 0.933이 나오면 특징 추출이 기존과 같은 것입니다.
4. **임계값 보정:** 대상 지역 표본에서 확률 임계값별 F1·클래스별 재현율을 보고 운영 임계값을 정합니다(인제: 0.2 권장, 정밀도 0.93 유지).
5. **육안 판독 검증:** `python paper/revision/inje_visual_check.py`
    - 모델 예측 유형별 25점씩 100점을 판독 순서를 섞어 체크리스트로 만듭니다.
    - 판독자는 `checklist_blind.csv`(라벨·예측 숨김)만 보고, Google Earth Pro 과거 영상이나 Esri Wayback으로 2019·2025를 비교해 칸을 채웁니다.
    - 채점은 `answer_key.csv`와 맞춰 봅니다(지도 라벨 대비, 모델 예측 대비 각각).
    - `index.html`의 Sentinel-2 영상 조각은 위치 확인용입니다. 2019년 영상은 구름 잔재로 흐린 곳이 있어 판정은 고해상도 영상으로 합니다.
6. **재학습 여부 판단:** 아래 기준 중 하나라도 해당하면 대상 지역 표본을 섞어 재학습합니다.
    - 임계값을 보정한 전이 F1이 대상 지역 자체 CV보다 0.05 이상 낮음
    - 특정 변화유형의 재현율이 0.5 미만으로 남음
    - 육안 판독에서 모델 예측 정확도가 지도 라벨 일치율보다 크게 낮음
7. **의사결정 서비스로 확장:** `forest_decision_agent`의 구축 스크립트는 춘천 경로가 상수로 들어 있습니다. 대상 지역 파일로 바꿔 다시 실행합니다.

| 파일 | 바꿀 항목 |
|---|---|
| `forest_decision_agent/build_db.py` | 임소반·사업실적 gpkg, 읍면동 경계, 산불·산사태, 임도·도로 gpkg(`GIS`), AE·S2 래스터 이름 |
| `forest_decision_agent/build_trajectory.py` | AE·S2 래스터, 임상도 폴더(`임상도 {연도} 51110`) |
| `forest_decision_agent/build_ae_classes.py`, `build_yearly_history.py` | AE 연도별 래스터 |
| `forest_decision_agent/tools.py` | `SOURCES` 설명, 지도 제목, 전체 지역 이름 |
| `scripts/gee_export_alphaearth_chuncheon.py`, `gee_export_sentinel_chuncheon.py` | 내보낼 지역 경계 |

## 5. 라벨 규칙 재정의 체크리스트 (다른 도면 체계일 때)

- 임상 코드: `FRTP_CD` 0 무립목지·비산림, 1 침엽수림, 2 활엽수림, 3 혼효림이 같은가
- 수종군 코드: 미립목지 `81`, 제지 `82`가 같은가 (벌채 = 산림 → 81, 전용 = 산림 → 그 밖의 비산림)
- 영급 체계: 10년 단위 1~9영급인가 (벌채·갱신 = 3영급 이상 → 1영급 이하)
- 두 도면 사이 기간: 6년(2019→2025)보다 길면 '무변화' 영급 증가 허용폭(+0~2)을 기간에 맞춰 조정
- 갱신년도 속성: 판독 갱신 시점이며 실제 변화 시점이 아님. 시점 평가는 사업실적·고시 같은 날짜 있는 기록으로
- 임상만 바뀌고 영급이 유지된 조각(임상 변화)과 판정 보류 조각은 학습에서 제외 — 춘천에서 이 조각들의 AE 거리 중앙값(0.033·0.034)이 무변화(0.032)와 같아 실제 피복 변화가 아닌 판독 차이로 봄

## 6. 한계

- 인제 시험은 같은 강원 산간 지역, 같은 임상도 체계 안의 전이입니다. 저지대·남부 활엽수림대 등 생태 조건이 다른 지역은 별도로 확인해야 합니다.
- 인제 자체 학습 기준선은 표본 2,100점으로, 블록 간 편차(±0.08~0.12)가 큽니다.
- 현장조사 자료가 없어 독립 검증은 사업실적 연도와 육안 판독으로 대신합니다.
- 춘천 S2 결과를 GEE에서 다시 계산하면 0.764로, 논문 수치 0.772와 조금 다릅니다(Sentinel-2 컬렉션 재처리 영향으로 추정). 같은 표에서 비교하는 값은 같은 시점에 다시 계산한 값을 씁니다.
